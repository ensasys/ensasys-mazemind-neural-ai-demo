How the learning loop works

This is a real, self-contained Deep Q-Network implementation in JavaScript. The network predicts the long-term value of four possible moves. It improves from rewards and past transitions instead of being given a route to follow.

04 · LearnBellman target + backpropagation

What makes this machine learning?

A neural network maps 12 inputs through two learned hidden layers to four Q-values. The DQN trains those weights with temporal-difference targets, mini-batches sampled from replay memory, and a periodically updated target network. ε-greedy exploration balances trying moves with using the current policy.
